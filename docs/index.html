Royal Addons for Elementor

Welcome to the official documentation. Use the sidebar to navigate through our extensive library of widgets and extensions.

Getting Started

Royal Addons for Elementor is a powerful plugin that enhances your Elementor page building experience. With over 150 widgets and extensions, you have all the tools needed to build stunning websites.

Tip: You can quickly find specific widgets by using the search bar in the top left corner.

How to use a Widget

1. Open any page or post with Elementor Editor.

2. In the left Elementor panel, scroll down to the "Royal Addons" category.

3. Drag and drop any widget into your page layout.

4. Customize the widget using the Content, Style, and Advanced tabs.

How to use an Extension

Extensions are usually located in the Elementor Advanced tab or within specific widget settings. For example, "Custom CSS" is found under the Advanced tab > Custom CSS.

Installation Guide

Learn how to install and activate Royal Addons for Elementor correctly on your WordPress website.

Prerequisites

Before installing Royal Addons, make sure you have the following installed and activated:

  • WordPress (latest version recommended)
  • Elementor Free Plugin

Automatic Installation

1. Log in to your WordPress Admin Dashboard.

2. Go to Plugins > Add New.

3. Search for "Royal Addons for Elementor".

4. Click Install Now next to the plugin.

5. Once installed, click Activate.

Manual Installation

If you prefer or need to install manually:

1. Download the plugin ZIP file from WordPress.org or our website.

2. Go to Plugins > Add New and click Upload Plugin at the top.

3. Choose the ZIP file and click Install Now.

4. Click Activate after successful installation.

Activating Pro: If you purchased Royal Addons Pro, navigate to the Royal Addons tab in your dashboard, enter your license key in the License section, and click Save to unlock Pro features.
