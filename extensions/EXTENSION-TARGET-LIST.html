🐛 Known Issues — Atomic Div Block সমস্যার কারণ

  • 1
    ভুল element name check: সব extensions-এ 'div-block' check করা হচ্ছে, কিন্তু Elementor 4-এর Atomic Div Block-এর actual get_name() returns 'e-div-block'। ফলে $is_atomic সবসময় false থাকে।
  • 2
    ভুল hook architecture: Atomic Div Block (Atomic_Element_Base) Controls_Stack extend করে না। তাই elementor/element/after_section_end hook কখনোই fire হয় না এই element-এর জন্য। Atomic elements-এর জন্য সম্পূর্ণ আলাদা hook/integration strategy দরকার।
  • 3
    section_advanced check too strict: সব atomic callbacks $section_id !== 'section_advanced' check করে return করে। নিয়মিত elements-এ এই section থাকলেও Atomic-এ নেই, তাই registration কখনো হয় না।
